# 监控器故障码

由 fault_codes.json 生成。此表覆盖本次 ClawVM 与 COM 门卫的主要故障。

| 代码 | 范围 | 原因 | 重放方式 |
|---|---|---|---|
| DIRTY_PAGES_PENDING | task | 脏页尚未建立检查点，或恢复清单/修订不匹配。 | 重放 page-status 后发生状态更新再 recover。 |
| PAGE_MANIFEST_INVALID | task | 页面清单缺字段、重复或降档序列非法。 | 加载同一份清单并去掉或重复页面 ID。 |
| TICKET_SCOPE | ticket | 票据与任务、房间或会话不一致。 | 用其他会话的票调用 claim。 |
| LEASE_DENIED | ticket | 未持有有效票或已过期。 | 用错误 lease 调 com-build。 |
| EVIDENCE_CHANGED | part | 验收输入文件或凭据发生变化。 | 验收后修改模型或台账。 |
| STALE_GENERATION | part | 事件中的零件版本不是当前版本。 | 在重建后重放旧保存事件。 |
| STALE_GENERATION_OR_PART | part | COM 请求的零件不存在或版本旧。 | 用旧 generation 提交 com-build。 |
| RECOVERY_PROOF_REQUIRED | task | 未提交可信排空确认和恢复理由。 | 隔离时省略 drained/reason。 |
| COM_GATE_REQUIRED | ticket | 旧命令记账入口在 COM 门卫模式禁用。 | 接管后调用 begin 或 part-saved。 |
| COM_OPERATION_DENIED | part | 操作未进入门卫白名单。 | 提交 Dispatch 或任意宏。 |
| COM_TIMEOUT | part | COM worker 超过执行期限。 | 模拟阻塞 worker 后观察回收和排队。 |
| COM_COMMIT_FAILED | part | 完成事件和状态未能一起落盘。 | 注入 SQLite 写入失败。 |
| COM_REPLAY_CONFLICT | part | 同一作业号被重放但参数不同。 | 修改参数后重放同 command。 |
| CLOSE_NOT_CONFIRMED | part | 未能验证已关闭建模文档。 | 让 CloseDoc 返回但文档仍存在。 |
| SW_INSTANCE_CHANGED_OR_MULTIPLE | task | 当前实例与服务持有身份不一致。 | 模拟第二个 SW 进程。 |
| AUDIT_CURSOR_INVALID | task | 事件分页参数超界。 | 请求负数 since_rev。 |
