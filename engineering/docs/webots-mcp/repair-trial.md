# A03 issue inspection and bounded CAD trial

With engineering/tools on PYTHONPATH, run `python -m webots_mcp.repair STATE TASK ROOM RUN ISSUE` for read-only attribution. The original S04 example keeps both synthetic box occurrences and an unknown root cause. The CLI does not request a SW lock. When a run has a raw observation, the A02 assembly module must be on the package path. A03 also uses the A04 physical_gate module for trials.

The trusted host API is `webots_mcp.repair_trial.trial(store, run, issue_id, policy, source_dir=..., room_label=..., operation_id=..., candidate_run=..., open_owned=..., export_candidate=..., retest=...)`. The host supplies the allowlist, owned session and callbacks independently of model text. It authenticates task and active room before invoking the API. The raw room label must hash to the store room. Live adapter bindings and host tool registration await I01. No CAD/Python expressions, generic custom scripts, free-form property writes or source promotion are supported.

## What constitutes admissible input

- Read all three reports via EvidenceStore. Experiment model/conversion links identify their exact run-local report bytes. A known issue references one observation by id. An observation references an indexed raw JSON object whose content is the observation excluding raw_sha256. It names its run, robot, world hash, generation, configuration, target(s), step, seconds, metric/value/unit. Preserve any accompanying native/contact/action/position, image and log evidence. For an A04 PositionSensor receipt, worker_observation reads the original runtime JSON without rewriting it. It checks exported model bytes and the manifest-indexed sensor-binding receipt (metric, device, robot, configuration, named targets, unit and positive scale); it derives the absolute sample step from simulation time, retaining the operation-local step separately. A03 recomputes that normalized observation and matches the sensor-binding hash to the A04 trace condition. Each target goes through A02 map_candidates. Candidate sets and missing mappings remain visible; the function never asserts a root cause from a contact.
- An approved policy fixes all three report hashes, component_id, kind=distance_mate, mate_reference, dimension full name, measured old_m, proposed new_m, min_m/max_m, reason and expected_improvement. Its root and files map declare a flat owned pack. The manifest must link actual indexed cad-pack-member snapshots and an exact source_pack mapping basename to SHA256. A copied candidate with ambiguous references or any external dependency is unsupported.
- Model/conversion inputs require supported, real-sw-export status, verified source/artifact bytes, no missing data, a supported conversion, no omissions and an indexed exported-model. Approximate A01 bundles currently cannot authorize writing.
- Experiment input must contain real-webots indexed evidence and a physics_pair with coarse/fine {run_id,sha256} and policy. physics-trace evidence holds JSON with A04 trace fields plus robot/world_sha256, excluding raw_evidence_sha256, which A03 adds from the verified receipt. Each collision coverage hash must identify a collision-coverage attachment under the respective owned run. Each decoded coverage attachment binds run_id, generation, robot, world_sha256 and pairs[pair] to the trace; contradictory detector metadata blocks the trial. The A04 evaluator is called again, and the report verdict must match. The issue measurement must match the representative coarse sample clock, maximum observed value, generation, robot, world, and frozen policy. time_step in experiment parameters is seconds; A04 step_ms is milliseconds. The supported metric has an explicit maximum. All reported threshold metrics are compared for regression.
- Baseline physical_valid=true + FAIL is an eligible experiment only when the measured criterion is violated. The rebuilt candidate requires physical_valid=true + PASS, same condition hashes except the exported model, identical scene, initial state, seed, controller actions, materials, time step, budget and thresholds. Synthetic inputs cannot grant write permission. A03 assumes immutable trusted evidence producers and a host-owned state directory. File hashes verify identity/integrity; they cannot authenticate a user-authored producer.

## Trial and recovery

One trial per baseline issue is enforced by exclusive claim; its operation ID cannot be reused. Snapshots and candidate files are retained under the owned baseline run, alongside trial.json. The original pack stays outside this directory. A trial requires the existing SW exclusive gate. Only a detached pack may be opened, using `opened_pack(authorized_owned_empty_sw_app, path)` or the corresponding trusted adapter. The observed dependency set must equal the approved pack. A02 verifies the occurrence; the feature must be an active distance mate involving that occurrence. The code verifies the exact writable dimension and old value, writes SI metres in the current configuration, checks rebuild and native error count, resolves the feature again, reads back the value, checks Save3 result/errors/warnings and closes the owned pack. It retains hashes of every file.

The host-provided export_candidate(path,new_run) runs under the same SW lock and must publish A01 model/conversion reports for the saved revision; A03 checks them before releasing the lock. retest(new_run,baseline_run) then runs A04 outside the SW lock and publishes a fresh experiment. A pre-existing experiment cannot substitute for dispatch. A03 verifies artifact hashes again after replay, records scores and returns a candidate for human review. It never promotes a candidate into the original CAD pack.

Failure restores each staged file from the verified snapshot. If closing the native session is uncertain, state is OUTCOME_UNKNOWN and staged files are quarantined. An interrupted journal or claim, including an empty claim, blocks replay. Confirm the owned app has released the files and reconcile actual file hashes and A04 operations before considering any restoration. Never restore over the user's original or rerun unknown actions.
